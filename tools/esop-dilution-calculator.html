ESOP pool dilution calculator

See how a pre-money option pool top-up splits dilution between founders and incoming investors, before the term sheet does the deciding for you.

Investors in Indian priced funding rounds routinely ask for the ESOP pool to be topped up as part of the round — and for that top-up to be created pre-money, meaning existing shareholders (largely founders) absorb the dilution, not the incoming investor. This calculator shows the arithmetic behind that ask, using the standard formula for a pre-money pool shuffle.

How this calculation works

When an option pool top-up is created pre-money, the target pool percentage and the investor's percentage are both carved out of the post-money cap table first — and whatever is left belongs to founders and existing shareholders. In formula terms: Investor % = Investment ÷ (Pre-money + Investment); Founders' resulting % = 100% − Target Pool % − Investor %. The "extra" dilution founders absorb, beyond the investment itself, is the gap between the target pool and the pool that already existed before the round.

Why this matters at term sheet stage, not after

The pool size and whether it is created pre-money or post-money is a negotiated term, not a fixed rule. Founders who understand this arithmetic before a term sheet arrives are in a materially better position to negotiate a smaller top-up, a later top-up, or a post-money mechanic — than founders discovering the effect for the first time in the definitive documents. Read the full context in ESOP pool sizing: what to decide before you need it.

This calculator is an illustrative estimate using a simplified, standard pre-money pool-shuffle formula. It does not account for multiple share classes, liquidation preferences, convertible instruments already on the cap table, rounding conventions, or deal-specific mechanics — and does not constitute legal or financial advice.
